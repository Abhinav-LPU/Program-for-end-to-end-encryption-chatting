# Program-for-end-to-end-encryption-chatting
A simple python program which reads and sends message in a language which no third party can understand.
Two python files act as different mobile phones and a text file act as chat data which collect messages from the two python files and allow those python files to read messages from each other.
Even if that chat data(text file) gets leaked, the third party will not be able to understand the messages. Only the person who has the encoder and decoder can understand the messages.
